# nostromo get

Get a config item from manifest

## Synopsis

Get a config item from manifest.
Nostromo config items are saved in the manifest.

Use this command to get keys to examine these settings:
verbose: boolean
aliasesOnly: boolean
backupCount: number

```
nostromo get [key] [flags]
```
