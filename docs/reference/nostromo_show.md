# nostromo show

Show nostromo configuration

## Synopsis

Prints nostromo config with command tree
and profile changes.

By default the config file is located at ~/.nostromo/ships/manifest.yaml.

Customize this with the $NOSTROMO_HOME environment variable

```
nostromo show [flags]
```

## Options

```
  -h, --help   help for show
  -j, --json   Show manifest as json
  -t, --tree   Show manifest as tree
  -y, --yaml   Show manifest as yaml
```

## Options inherited from parent commands

```
  -v, --verbose   show verbose logging
```
